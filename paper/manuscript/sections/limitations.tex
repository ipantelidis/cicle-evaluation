\section*{Limitations}
\label{sec:limitations}

Our study covers single-label classification in English, and GoEmotions is restricted to its single-label comments. Our label spaces have at most 59 classes, so listing every label costs little here, and for label spaces with hundreds or thousands of classes only the candidate set can be listed. CICLe is defined for a single label per input, so multi-label narrowing would need a different set construction.
Every test sample holds 1,000 instances per seed. The paired bootstrap resolves differences of about half a point over the six-model grid, but per-model intervals (12 or 6 pairs) are two to three points wide, and the seed-42 checks of Section~\ref{sec:res-alpha} are directional only.
In the controlled-imbalance experiments the labelled pool is long-tailed but the test sample stays balanced, so the reported macro-F1 describes a deployment whose test distribution differs from its training distribution. A test sample with the same skew would weight the rare classes less.
The LLM configurations are not selected on held-out data. We report one fixed configuration (Per-Class, $k=4$, $\alpha=0.05$) as the main number and state when a best configuration is chosen on the test set. The miscoverage level is likewise reported as an ablation, and the rule for choosing it is a heuristic.
The conformal guarantee is per class and marginal over inputs within a class. It assumes that calibration and test data are exchangeable, which the pool-size and imbalance experiments respect by construction but a deployment may not.
We checked one prompt family with one alternative wording and one example order, on one seed. Six open models with 3B to 8B parameters form the main grid, and the 12B and 32B models are run on the five short-text datasets only. % PENDING: 12B and 32B on MASSIVE
 Proprietary models and models above 32B parameters are not covered.
Label renaming is an extreme stress test. Real deployments lie between informative and meaningless label names.
The supervised baselines use one untuned fine-tuning recipe, which is unstable for RoBERTa-large on the smallest pools, so the encoder numbers are a floor rather than a ceiling for fine-tuning. % PENDING (rerun): RoBERTa-large at the smallest pools
