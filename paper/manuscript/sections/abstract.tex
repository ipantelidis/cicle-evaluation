\begin{abstract}
In-context classification with small large language models (LLMs) is hard when there are many classes and the labelled data are skewed.
A small classifier can narrow the label set before prompting, which raises the question of how it should narrow.
We compare narrowing rules built from the same classifier on six English datasets with eight open LLMs, pairing every comparison instance by instance.
When the labelled pool is long-tailed, class-conditional conformal sets, as used by Conformal In-Context Learning (CICLe), keep about 90\% coverage or more on every class, while top-$k$, probability-mass and marginal conformal sets lose the rarest classes and 4 to 13 macro-F1 points.
Narrowing also gives a small, reliable gain over few-shot prompting, 0.5 to 1.8 points with 11 to 45\% shorter prompts, largest when label names carry no meaning. % PENDING: MASSIVE changes both ranges
With plentiful balanced labels a fine-tuned encoder is the better choice.
